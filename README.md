# Sobre o projeto

DSCommerce é uma aplicação **full stack web** construída durante a formação Dev Moderno, da empresa [DevSuperior](https://devsuperior.com "Site da DevSuperior").

Esta aplicação consiste em um sistema de e-commerce desenvolvido para disponibilizar um catálogo de produtos aos usuários, permitindo a visualização de itens, adição ao carrinho de compras e gerenciamento do processo de compra. 

**O sistema possui controle de perfis de usuário**, distinguindo usuários comuns e usuários administrativos. Usuários administrativos têm acesso às funcionalidades de CRUD de produtos, possibilitando o gerenciamento completo do catálogo.

# Tecnologias utilizadas
## Back end
- Java
- Spring Boot
- JPA / Hibernate
- Maven
## Front end
- HTML / CSS / JS / TypeScript
- ReactJS
## Banco de dados
- PostgreSQL

# Como executar o projeto

## Back end
Pré-requisitos: Java 11

```bash
# clonar repositório
git clone https://github.com/leovcorreia/08Backend/tree/main/dscommerce

# executar o projeto
./mvnw spring-boot:run
```

## Front end web
Pré-requisitos: npm / yarn

```bash
# clonar repositório
git clone git@github.com:leovcorreia/10Frontend.git

# entrar na pasta do projeto front end web
cd dscommerce-frontend

# instalar dependências
yarn install

# executar o projeto
yarn start
yarn dev
```
